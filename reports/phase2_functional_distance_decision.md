# Decision after functional-prediction and distance-decay tests

## Decision

**Both preregistered hypotheses passed after Holm correction. Proceed to the explicit-reproduction model-development track.**

The historical Phase 2 categorical block-beta NO-GO remains unchanged.

## H1: composition predicts standardized execution behavior

Across ten matched seed averages:

- mean Mantel Spearman correlation: **0.284521**;
- 95% bootstrap interval: **[0.259729, 0.309913]**;
- exact one-sided sign-flip: **p = 0.000977**;
- positive seed averages: **10/10**;
- Holm decision: **pass**.

All 20 individual run-level Mantel tests were significant. Similar eleven-part opcode compositions therefore carried reproducible information about similarity in standardized BFF execution outcomes.

This is a moderate association, not identity. The assay removed pool scarcity, mutation, and energy and used four fixed partners, so it measures controlled execution potential rather than realized ecological fitness.

## H2: composition similarity decays with spatial distance

Radius-1 minus radius-8 decay-strength excess:

- mean paired effect: **+0.00013480 similarity units/cell**;
- 95% bootstrap interval: **[+0.00010728, +0.00016145]**;
- exact one-sided sign-flip: **p = 0.000977**;
- positive pairs: **10/10**;
- Holm decision: **pass**.

Mean decay-strength excess was `0.00019976` at radius 1 and `0.00006496` at radius 8. The absolute slopes are small, but radius-1 decay was stronger in every matched seed and all radius-1 within-run null tests passed.

## Integrated interpretation

The evidence now supports a connected but bounded chain:

1. local interaction increases positional byte similarity;
2. local interaction increases graded opcode-composition similarity;
3. the graded effect persists through 50,000 ticks;
4. opcode-composition similarity predicts similarity in a standardized execution assay;
5. composition similarity declines with spatial distance, more strongly under radius-1 interaction.

This is evidence for spatially structured, behavior-relevant tape chemistry. It is not evidence for organisms because Stage 2 has no endogenous birth, inherited ecological lineage, organizational closure, or adaptive fitness.

## Next decision

Proceed with Stage 3R as an explicitly labeled mechanism prototype:

- pool-funded exact-copy birth;
- local offspring placement;
- parent–child lineage;
- neutral lineage-patch analysis;
- energy disabled to isolate reproduction.

The birth operator is scheduled and neutral, so any resulting lineage patch is a mechanism positive control rather than evolved self-reproduction.

## 500,000-tick matched-radius confirmation

**Deferred.** It is not currently required for a future gate:

- the continuous locality endpoint already passed at 5,000 and 50,000 ticks on 20/20 matched pairs;
- functional prediction and distance decay now independently pass;
- the next scientific uncertainty concerns reproduction and lineage, which changes the model.

A 500,000-tick radius comparison should be launched only if a later protocol explicitly requires very-long persistence in the unchanged Stage 2 model. Running it now would consume substantial time without resolving the organism-level question.
