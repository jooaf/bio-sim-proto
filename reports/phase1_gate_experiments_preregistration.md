# Phase 1 remaining-gate experiment preregistration

## Scope

This follow-up addresses only the two open Phase 1 items:

1. explicit metabolic path tracing in the conserved BFF soup;
2. SKI substrate validation through the existing world, scheduler, conservation, and logging pipeline.

No energy, dissolution, space, signals, task bias, fitness function, or designed replicator will be introduced.

## A. Explicit metabolic path tracing

### Question

Can we reconstruct explicit acquire→return→reacquire paths and determine whether blocked-write bursts are generated by one long interaction or many coordinated interactions?

### Token-labeling convention

Physical bytes of the same value are indistinguishable. For auditability, each initial tape byte and free-pool byte receives a bookkeeping token ID. Pool exchange uses deterministic LIFO selection within each symbol. This labeling does not change byte-level physics; it produces one valid token-level witness among equivalent labelings.

A successful changing write:

1. withdraws one token carrying the requested symbol;
2. returns the overwritten token to its symbol-specific pool stack;
3. records the destination tape as the returning donor for that token;
4. if the withdrawn token was previously returned, records donor tape → receiver tape, pool residence time, opcode, and interaction.

### Confirmatory hypotheses

- **M1:** Returned tokens are reacquired by tapes in every condition.
- **M2:** Some reacquired tokens cross tape identity (`donor != receiver`), establishing explicit pool-mediated tape-to-tape matter paths.
- **M3:** The donor→receiver flow graph contains reciprocal edges or directed cycles, demonstrating repeated matter circulation rather than one-way accumulation.
- **M4:** At multipliers 2 and 16, extreme blocked epochs are dominated by one interaction and one requested symbol; multiplier 0.5 should be broader.

### Matrix

- Population: 256 BFF tapes
- Epochs: 20,000
- Mutation: 1/4,096
- Multipliers: 0.5, 2, 16
- Seeds: 0–2
- Pairing: deterministic shuffled disjoint
- Token-event sampling: deterministic, bounded; aggregate token-flow edges remain complete

### Required outputs

- exact byte and token conservation checks;
- per-epoch burst summaries;
- complete donor→receiver edge counts;
- per-token return/reacquisition totals;
- bounded sampled token event paths;
- a report that distinguishes labeling-dependent token paths from labeling-invariant value flow.

## B. SKI substrate independence

### Question

Can a conservation-aware SKI chemistry execute through the same `FlatWorld`, `Scheduler`, interaction runner, invariant checker, and Parquet logger without substrate-specific changes to those modules?

### Representation and chemistry

Each fixed tape contains one prefix-encoded SKI expression followed by zero padding:

- `S`, `K`, `I`: combinator atoms;
- `@`: application node;
- `0`: empty padding.

For an ordered interaction `(A, B)`, construct application `A B`, perform bounded leftmost-outermost SKI reduction, and atomically replace A if the result fits one tape and the conserved pool can supply its net symbols. B remains available as the interaction partner, so application can acquire its symbols only by withdrawing matching conserved tokens from the pool.

Reduction rules:

- `I x → x`
- `K x y → x`
- `S x y z → x z (y z)`

Atomic batch replacement is required because a partially applied serialized rewrite is not a valid chemical reaction. Adding a generic atomic batch method to the write-mediator boundary is permitted; changes to `world.py`, `scheduler.py`, or `soup/logging/` are not.

### Confirmatory criteria

- **S1:** Hand-worked I, K, and S reductions are correct.
- **S2:** A blocked batch rewrite leaves tape and pool byte-identical.
- **S3:** Exact 256-component conservation holds throughout every run.
- **S4:** Same seed/config produces deterministic raw Parquet outputs.
- **S5:** Multipliers 0.5, 2, and 16 produce measurable, ordered scarcity responses.
- **S6:** SKI runs through unchanged `world.py`, `scheduler.py`, and `soup/logging/`; every forced core/interface change is reported.

### Matrix

- Smoke and hand-worked unit tests
- Determinism: two identical short runs
- Conservation/sensitivity: multipliers 0.5, 2, 16; seeds 0–2
- Population: 256 tapes
- Duration selected after a bounded benchmark, with identical duration across cells
- Mutation: zero, because arbitrary byte mutation usually destroys prefix grammar and would confound substrate validation

## Decision rules

The Phase 1 gate closes only if:

1. explicit cross-tape return/reacquisition and cyclic flow are observed without invariant failure;
2. SKI reductions and atomic blocking are correct;
3. SKI completes the replicated matrix with exact conservation and deterministic output;
4. no substrate-specific changes are needed in world, scheduler, or logging.

A negative ecological result does not fail substrate validation. Mechanical correctness and pipeline independence are the SKI objectives.
